# 文档索引

`docs/` 放**需要展开写**的东西。

## 各份文档写什么

| 文档 | 读者 | 内容 |
| --- | --- | --- |
| [`INSTALL.md`](INSTALL.md) | 维护者（AI） | 安装、搬家、升级的完整步骤，每步都带验证方式 |
| [`ARCHITECTURE.md`](ARCHITECTURE.md) | 维护者 | 分层约束、插件契约、配置 schema、事件表、话题归属不变式、已知技术债 |
| [`FEATURES.md`](FEATURES.md) | 使用者 + 维护者 | 逐个功能的行为、边界、怎么用；哪些做不到 |
| [`TROUBLESHOOTING.md`](TROUBLESHOOTING.md) | 维护者 | 日常命令、日志清单、故障速查表、自测说明 |
| [`tasks/README.md`](tasks/README.md) | 维护者 | 任务台账的规则：编号、命名、头部模板、索引维护 |
| [`tasks/INDEX.md`](tasks/INDEX.md) | 维护者 | 任务清单，一行一个任务，看总览用 |
