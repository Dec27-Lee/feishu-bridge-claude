# 支持的功能

> 这份清单是给**用户**看的：先看这里有什么，再让 AI 帮你装。
> 每一项都标了「怎么用」和「装不装」——不是所有功能都要装。

---

## 装在哪个插件里

功能都按插件组织。不用的插件直接删目录即可，其余照常跑。

| 插件 | 干什么 | 必需？ |
| --- | --- | --- |
| `core` | 话题路由、开窗、恢复会话 | **必需**，删了整套不成立 |
| `ask` | 手机上答窗口的选择题 | 可选 |
| `permission` | 手机上点「允许/拒绝」工具调用 | 可选 |
| `notify` | 窗口干完活推通知 | 可选 |

删一个可选插件的效果：`ask` 删了 → 题目只在终端弹；`permission` 删了 → 权限框只在终端；
`notify` 删了 → 不再主动推消息，但你发消息进去照样能收到回复。

## 一、日常操控

### 1. 每个窗口一棵话题

窗口干完活或需要你介入时，会在飞书群里发一条消息，自成（或接进）一棵属于它的**话题**。
话题名就是该窗口的会话名（你在 Claude Code 里 `/rename` 过的名字优先）。

**在那个话题里直接打字就行**，不用引用、不用 @。消息会路由到对应窗口。

> 一个群里可以有很多话题，各自对应一个窗口。话题列表按最近活跃排序。

### 2. 从飞书新开一个窗口

在群里**发一条新消息**（不要进已有话题）。这条消息不回发给 Claude，只当作「我要开窗口」，
但它**就是话题名**——所以直接写任务名，别写「开个窗口」：

```
修一下订单列表的分页
```

机器人回一张「选择工作区」卡片，列出它自己发现的最近用过的目录。然后：

- 点按钮 ← 首选
- 或直接在这个话题里回序号（`1`）← 按钮点不动的兜底
- 也可以一开始就写 `#目录名` 跳过选择

选完后窗口起来（3–10 秒），回一张绿色「窗口已创建」。之后在这个话题里发正文即可。

> **话题名改不了**：飞书没有改话题名的接口。开窗时想好。

### 3. 恢复历史会话

在群里**新开一个话题**，发 `#resume`（也认 `#恢复`、`#继续`）。
机器人列出近 5 天、当前没在运行、且同工作区的会话，点一个，新窗口接续它。

> 三个过滤条件缺一不可：太久远的、正在运行的、别的目录的都不列。
> 同一份会话不能被两个窗口同时打开——跨目录恢复会把对话带到错误的目录。

### 4. 换工作区 / 再开一个窗口

窗口就绪卡片底部有两个按钮，随时可点：

| 按钮 | 作用 |
| --- | --- |
| **🔁 换会话（resume）** | 弹会话选择，新窗口接续它；**本话题改绑到新窗口** |
| **➕ 再开一个窗口** | 弹工作区选择，在群里**另起一棵新话题**；本话题不动 |

## 二、远程作答

### 5. 答窗口的选择题

窗口用选择题问你时，**分两种情况**：

| 你在哪 | 会发生什么 |
| --- | --- |
| **人在电脑前** | 弹窗直接出在终端，你像平常一样按；飞书只推一张蓝色提醒卡，**不用在飞书答** |
| **人不在** | 推一张带选项的卡片，点选项就把答案送回窗口；**一直等你，不会几分钟就收走** |

「人在电脑前」的判定只有两条，必须同时满足：

1. **没锁屏**
2. **3 分钟内有键盘或鼠标输入**

> 只看空闲时长不够——你可能刚敲完就锁屏走了，那时空闲还是 0 秒。
> 人在电脑前哪怕在看浏览器、看别的窗口，也算「在」：弹窗直接给你比掏手机快。

不在电脑前时：

| 情况 | 怎么答 |
| --- | --- |
| 单选 | 点一下选项，答案立刻送回 |
| 多选 | 点几个再点「✅ 就这些」 |
| 选项里没有的答案 | 直接在话题里**回文字** |
| 一次问了好几题 | 卡片一题一题来，答完自动出下一题 |
| 你其实就在电脑前 | 点「🖥 我在电脑前，让终端问我」，弹窗立刻回终端 |

> **为什么一直等**：人不在时手机是唯一通道。到点把弹窗扔回终端，等于丢给一个没人看的屏幕，
> 你回来时窗口可能已经被后来的输出刷走了，反而更答不了。默认等 30 分钟（`awayWaitSeconds`）。
>
> 三个提前结束条件：你答了 / **你回到电脑前（解锁、动键鼠）** / 桥接挂了。

### 6. 放行一个工具操作

窗口要动你真东西时（跑命令、改文件、抓网页），人不在才推这张橙色卡片：

```
🔐 等你放行一个操作
🔧 工具：Bash
rm -rf build
[✅ 允许这一次] [✅ 允许，本会话不再问这个工具]
[⛔ 拒绝]     [🖥 我在电脑前，让终端问我]
```

- **允许这一次**：只放过这次，下次还问
- **允许，本会话不再问**：顺带把规则写进本项目 `.claude/settings.local.json`
- **拒绝**：窗口收到理由，可换个做法

> **这几类问了也放不过**，卡片不会出现，直接在终端等：命中 `deny` 规则的操作、
> 强制人工交互的 MCP 工具、网络路径读取、关键路径的 `rm`。
> `dontAsk` 模式下本机制不生效。定位是「帮人点一下」，不是「绕过权限」。

## 三、通知与上下文

### 7. 任务完成通知

窗口一轮跑完，把结果推到它自己的话题。卡片头部带这一轮的状态：

```
📁 E:/Develop_E/temp-workspace
🕐 00:46:58
📦 ██░░ 50% 248k · Tokens 418.4M
─────────────────────────
💬 你在终端里说
│ 把登录页的表单校验补上
─────────────────────────
（AI 的回答）
```

第三行依次是：上下文用量进度条、占用百分比、当前上下文 tokens、本会话累计消耗。

**「你在终端里说」那一块**是为了手机上看不到终端的人：你在电脑前敲的那句话，
飞书这头本来完全不知道，只能看到 AI 在自说自话。现在会把它一起推过来。

- 这一轮如果是**从飞书发起**的，就不会重复推回来（那句话本来就在飞书上）
- 系统自己塞进对话的东西（后台任务回执、斜杠命令回显、compact 摘要）不会被误当成你打的字
- 你粘贴进来的内容会保留，外面的那层包装标签会剥掉
- 太长会截到 300 字，不影响下面正文
- 不想要这个块：`config.json` 里 `plugins.notify.showUserPrompt: false`

### 8. 需要你介入时的提醒

窗口弹权限框、要你输入、或子代理需要人时，会推一张提醒卡并 **@ 你**。
话题一多，新卡片很容易被淹没，@ 能直接把人叫过来。

### 9. 图片转发

在飞书里发图片，桥接会下载到本地并把路径拼进消息正文，
窗口里的 Claude 可以用 Read 工具直接读图。

### 10. 话题自动置顶

每开一个新窗口，顺手把它的话题置顶。话题多了以后在飞书「置顶」里直接点进去。
（飞书没有「订阅单个话题」的接口，所以用置顶代替。可在配置里关掉。）

## 四、想加自己的功能

功能是插件，加功能 = 加一个目录，不用改内核：

```
plugins/<你的插件id>/
  plugin.json    清单：id、配置默认值、要接的 hook
  index.js       常驻服务，导出 { start(ctx), stop(ctx) }
```

`ctx` 上能拿到什么、插件之间怎么通信（事件总线）、有哪些约束，
全部写在 [`docs/ARCHITECTURE.md`](ARCHITECTURE.md) 第 5 节，也有个完整的
「日报提醒」示例（第 10 节）。

判断标准很简单：**如果你要做的事需要读飞书消息或往飞书发消息，那只是订阅一个事件；
如果需要定时做事，就在 `index.js` 里起定时器。** 不需要动 `kernel/` 里任何一行。

## 五、明确不支持的

| 做不到 | 原因 |
| --- | --- |
| 一个飞书应用变多个机器人 | 飞书的应用和机器人是一对一，机器人名不能动态改 |
| 改已有话题的名字 | 飞书没有这个接口，只能重开话题 |
| 在飞书上模拟按键操作终端 | 走的是官方 hook 通道，不是模拟输入 |
| 绕过 Claude Code 的权限系统 | 设计如此：`deny` 规则优先于任何 hook 返回值 |
| headless / 后台子代理里代答 | 这些场景没有 hook 返回决策时 Claude Code 会直接拒绝工具调用 |
