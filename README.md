# Feishu Bridge Claude

用飞书手机端远程操控本机多个 Claude Code 窗口：
每个窗口在飞书群里有一棵自己的话题，群里打字就是给它发消息；手机上一句话就能答选择题、点权限确认。

**这个仓库是给 AI 装、给 AI 养的。** 你不需要读代码——把仓库地址丢给 Claude Code，
说「帮我装一下」即可。它知道该检测什么、该改哪个文件、怎么验证。

---

## 它解决什么问题

电脑上同时开着好几个 Claude Code 窗口在干活，一旦你离开电脑：

- 不知道哪个窗口跑完了 → 每个窗口在自己的飞书话题里汇报结果
- 想给某个窗口补一句话 → 在那个话题里直接打字
- 窗口弹了个选择题等你选 → 手机上点一下
- 窗口要执行命令等你放行 → 手机上点「允许」

**人在电脑前时它不会来打扰你**：弹窗照常出现在终端里，飞书只推一张不带按钮的提醒卡。
只有你锁屏或离开几分钟后，才会把等待搬到手机上。

## 支持的能力

| 能力 | 说明 |
| --- | --- |
| 话题路由 | 每个窗口一棵话题，话题名就是会话名；在里面打字即发消息 |
| 远程作答 | 选择题、多选、自定义答案都能在手机上完成 |
| 远程放行 | 权限确认卡上点「允许 / 拒绝 / 本会话不再问」 |
| 任务通知 | 一轮跑完把回复推到话题，卡片带上下文用量和你这句在终端里说的话 |
| 从飞书开窗 | 新建话题 → 选工作区 → 电脑上自动开一个干净的终端窗口 |
| 恢复会话 | 在一个话题里 `#resume`，把历史会话接到这个话题上继续 |
| 话题置顶 | 新窗口的话题自动置顶，群一多也找得到 |
| 图片转发 | 飞书里发图，桥接下载到本地并把路径交给窗口 |
| 网页改配置 | `node setup/config-ui.js` 起一个本机页面，字段与校验都从配置结构生成 |
| 开机自启 | 三个平台各自的原生机制，崩溃自动重拉 |

人在不在电脑前，只有两条判据：**没锁屏** + **3 分钟内有键鼠输入**。
采不到就如实降级（一律推卡片），不编数据、也不阻塞。

详细功能见 [`docs/FEATURES.md`](docs/FEATURES.md)。

## 支持平台

| 功能 | Windows | macOS | Linux |
| --- | --- | --- | --- |
| 话题路由、卡片作答、任务通知 | ✅ | ✅ | ✅ |
| 识别「人在不在电脑前」 | ✅ | ✅ | ✅ * |
| 从飞书新开窗口 | ✅ Windows Terminal | ✅ Terminal / iTerm | ✅ 常见终端 |
| 开机自启 | ✅ 启动文件夹 | ✅ launchd | ✅ systemd --user |

\* Linux 的空闲时长靠 `xprintidle`（X11），Wayland 下拿不到；拿不到时如实报「不知道」，
判定会退到「一律推卡片」——不编数据，也不阻塞。

任何一项缺失都**自动降级**，不会报错：没有在场探测就一律推卡片等你答，
不能自动开窗就手动开一个窗口用 `#resume` 绑定话题。主体能力与平台无关。

## 开始使用

> **先定好放在哪个目录再装。** 这个项目装完就是你电脑上实际运行的程序——
> 开机自启、每个窗口的 hook 调的都是这个目录。别 clone 到桌面或下载目录里就开装。
> 以后要换位置也不用重装：`node setup/move.js <新目录>`。

```bash
git clone https://github.com/Dec27-Lee/feishu-bridge-claude.git
cd feishu-bridge-claude
node setup/check.js      # 先看缺什么
npm run install          # 按提示装（会先 dry-run 给你看要改什么）
npm run verify           # 联调：真的调飞书 API 确认通
npm start                # 启动
```

需要 Node.js ≥ 18（推荐 22+），以及一个飞书**企业自建应用**的机器人。
飞书那边的准备（建应用、导权限、订事件、拉群）**必须你手动做**——
AI 会给你一份可以直接粘贴导入的权限清单，但点按钮只能你点。

完整步骤见 [`docs/INSTALL.md`](docs/INSTALL.md)。

### 以后更新

```bash
node setup/update.js     # 拉取 + 迁移配置 + 体检，一条命令
```

### 想换个目录放

```bash
node setup/move.js D:/tools/feishu-bridge-claude            # 演练
node setup/move.js D:/tools/feishu-bridge-claude --yes      # 真搬
```

它会停进程、复制、把 hooks / cc-switch / 开机自启改指到新位置、再启动体检。
**别手工拖文件夹**——路径被写在四处，漏一处就会「看着在跑，改代码没反应」。

## 架构

```
platform/   与操作系统相关的一切（开窗、进程校验、在场采样器）
kernel/     与业务无关的基础设施（配置、日志、会话表、插件加载器）
plugins/    业务功能，可增删
  core/         路由 + 开窗 + 恢复会话（必需）
  ask/          远程代答选择题
  permission/   远程点权限确认
  notify/       任务完成通知
```

**插件之间不互相依赖，只通过内核的事件总线通信**——所以一个功能出问题，
删掉那个目录就行，其余照常跑。加功能也是加一个目录。

细节见 [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md)。

## 安全边界

这套东西会代替你回答提问、放行工具调用。它**不能**绕过任何权限：命中 `deny` 规则的操作、
强制人工交互的 MCP 工具、`dontAsk` 模式下都不生效。定位是「帮人点一下」，不是「替人做主」。

所有写系统配置的操作都会先备份，并支持 `--dry-run` 预览。
